# VF-VHQ-W3.1 — Legacy Rollback Fix Report

## Root fix

**Cause:** After W3.1 nested `#vhq-shell` inside `#view-hq` → `.coi-shell`, legacy `vhqSetBackdropInert(true)` applied `inert` + `visibility:hidden` to `.coi-shell` — an **ancestor** of the shell → blank modal.

**Fix (portal + sibling inert):**
1. On legacy open: **portal** `#vhq-shell` to `document.body` (sibling of `.coi-shell`).
2. Inert only `body > *` peers that do **not** contain the shell (never ancestors).
3. On close / primary restore: clear inert, move shell back into `#view-hq`.
4. Restored legacy `vhqOpenOperationsConsole` (Sign in) — previous W3.1 stub recursed into `vhqGoConsole` and would stack-overflow.

Primary path unchanged: shell stays in `#view-hq`, `position:relative`, no dialog/inert.
